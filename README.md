# SOLAR CUP TWO LIVE

曜日盃 TWO 的手機優先當日賽務查詢前端。

## 功能

- 賽程推進狀態與 310 場完成進度
- 十面場地 LIVE 卡片
- 關注 1～3 隊並依場地前方場次提示
- 資格賽、階級分流與晉級狀態入口
- 球團總積分／力場排行
- PWA 安裝與站內／系統通知（**通知僅在 App 開啟時運作**，非 Web Push；iOS 需先「加入主畫面」再開啟通知）

## 資料

賽程骨架與隊伍主檔沿用 `solarcup-info` 的公開資料檔；比分讀取既有 Google Sheets 發布分頁。此 Repository 獨立部署，不會修改原網站。

## 本機預覽

以任意靜態伺服器開啟專案根目錄即可，例如：

```bash
python3 -m http.server 8080
```

## 通知的限制

本站不使用 Web Push（後端無推播伺服器）。系統通知由頁面本身觸發：

- App（或瀏覽器分頁）開啟時才會發出提醒；關閉後不會收到任何通知
- iPhone／iPad 需先以 Safari「加入主畫面」，從主畫面開啟後才能授權通知
- 授權後頂欄鈴鐺亮黃點；站內橫幅提醒不受權限影響，一律可用
